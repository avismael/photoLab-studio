# Fuentes de FotoLab

Distribuciones originales de [Google Fonts](https://github.com/google/fonts/tree/main/ofl), alojadas en esta aplicación para evitar conexiones externas al editar o exportar.

| Familia | Carpeta upstream | Estilos incluidos |
| --- | --- | --- |
| Inter | `ofl/inter` | Variable normal y cursiva |
| Roboto | `ofl/roboto` | Variable normal y cursiva |
| Montserrat | `ofl/montserrat` | Variable normal y cursiva |
| Oswald | `ofl/oswald` | Variable normal |
| Bebas Neue | `ofl/bebasneue` | Regular |
| Playfair Display | `ofl/playfairdisplay` | Variable normal y cursiva |
| Lora | `ofl/lora` | Variable normal y cursiva |
| Caveat | `ofl/caveat` | Variable normal |

Descargadas del repositorio Google Fonts el 23 de octubre de 2026, sin modificar los archivos TTF; los nombres locales se simplifican para las URLs. Se conserva la licencia SIL Open Font License 1.1 de cada familia en los archivos `*-OFL.txt`. `fonts.css` declara únicamente los estilos incluidos: la interfaz desactiva negrita o cursiva cuando no se dispone de ellos.

Las fuentes incluyen los caracteres latinos y acentos originales. La cobertura de otros alfabetos depende de la familia elegida.
